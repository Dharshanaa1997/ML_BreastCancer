# AI-Enterprise-Lab-2
This repository contains machine learning models for the Breast Cancer Wisconsin (Diagnostic) dataset.

## Models Included
- **Decision Tree Classifier (`dharsana_model_v1.py`)**: Achieved an accuracy of 95%.
- **K-Nearest Neighbors Classifier (`dharsana_model_v2.py`)**: Achieved an accuracy of 96%.

## Dataset
The dataset is sourced from [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/breast+cancer+wisconsin+(diagnostic)).

## How to Use
Run the scripts using Python and ensure required packages (`scikit-learn`, `pandas`) are installed.
